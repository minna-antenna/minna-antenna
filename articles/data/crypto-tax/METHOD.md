# 第7号：対象条件を限定した税額モデル

調査日2026-11-06 UTC。採用資料の整合性とモデルの適用条件を検証する。
No.2260の前提未記載例は根拠から除外し、不一致と採否を監査記録に保持する。
`scripts/verify_crypto_tax_sources.py` は必要な一次資料・確認記録・対象年・除外資料の再混入・重要な未解決事項を検査する。

## 対象年と仮定

2025年分（適用済み参考）と2026年分（2026-12-01施行規定を反映した通常の申告）。
施行前の死亡・出国による準確定申告等を含めない。2026年分を調査日に既に施行済みだと扱わない。
単身居住の会社員。給与年収400/800/1200万円、給与所得276/610/1005万円。
社会保険料60/120/180万円は固定の仮定。他の所得、扶養・配偶者・障害、医療・生命保険・寄附金・住宅ローン控除等なし。
利益10/50/100/300万円は原価・経費控除後。事実関係として雑所得を仮定するが、利益額から所得区分を判定しない。
勤務先の健康保険・厚生年金を前提に国保等の増加は計算外。
全所得を確定申告へ含める条件。10万円のモデルを、申告不要条件に該当した人の納付額と同一視しない。

## 計算と端数

合計所得に従って基礎控除を毎回再判定。2025年分と2026年分の控除表を分ける。
モデル給与400万円は給与別表に関係する4,000円区切りに一致し、例示の給与所得は276万円。
所得税課税所得を1,000円未満切捨てし、7段階の税率・速算控除で所得税本体を計算。
復興特別所得税 = 対象税額控除後の基準所得税額×2.1%、1円未満切捨て。本モデルの対象税額控除は明示的に0円。
給与のみで年末調整した源泉徴収額は、給与のみ本体＋復興税の100円未満切捨て値と仮定。
暗号所得込みの国税合計から同源泉徴収額を引き、納付段階100円未満切捨て。
表の国税増分は「暗号所得込み年税額100円切捨て−給与だけの年税額100円切捨て」と一致する。
所得税増分と復興税増分は処理前の内訳なので、国税納付増分との端数差がある。

住民税：標準6%+4%、基礎控除43万円。扶養なしの基礎控除の人的控除差5万円に対する調整控除を
市区1,500円・都道府県1,000円として計算。課税標準1,000円未満切捨て、各税額100円未満切捨て。
全モデルは非課税基準と人的控除差を十分上回る。給与のみ/暗号ありで均等割・森林環境税は同額として増分で相殺。
自治体の超過課税なし。実在の個人の年度税額の保証ではない。
年分と住民税年度は1年ずれる。2025年所得は原則2026年度、2026年所得は原則2027年度。

## 再現

```sh
python scripts/audit_crypto_tax.py
python -m unittest discover -s tests -v
```

全テストには、採用資料の整合性ゲートと、その不備を必ず拒否する負例テストを含める。
計算監査は別のDecimal実装で累進区間を積み上げ、速算表方式と24件192チェックを照合。
生成は `python scripts/calculate_crypto_tax.py`。表・CSV・JSON・コード写しを同時に生成。
図の再生成は `python scripts/calculate_crypto_tax.py --plots`（任意依存matplotlib）。

公式資料の例示：所得税974,000円に対して復興税計算基礎が947,000円。
速算表と2.1%からの独立計算は974,000円・20,454円。掲載例19,887円をモデルへ転記していない。
No.2260の例自体の原因は未解明。法令・No.1000等を代替根拠とし、この例を掲載数値の根拠に使わない。


## 算出税額と基準所得税額の区別（追加監査）

課税所得→所得税法89条の算出所得税額→基準所得税額を減らす対象の税額控除等→基準所得税額→復興税の順。
源泉徴収・予定納税は原則その後の納付計算。速算表の636,000円は個別税額控除ではない。
復興財源確保法10条・12条・13条と国税庁No.1000で確認。外国税額控除等の除外にも注意。
元の24モデルは税額控除0円のため計算結果は変わらず、CSVは前コミットとバイト一致。
JSONには算出所得税額・対象税額控除0円・基準所得税額を分けて保存。
`national_tax_components` は基準額を減らす対象控除が確定した場合の算数だけを扱い、控除資格や外国税額控除等は判定しない。
未知の控除額Noneを0円へ変換しない。仮定の27,000円控除なら947,000円/19,887円を再現するが、公式例の事実とは扱わない。
No.2260には27,000円の税額控除の記載がない。誤記か未記載条件かを決めつけない。公開ゲートは採用する根拠の整合性・適用条件を検査する。
新しい独立監査では既存192チェックに加え、基準額の段階を96チェック確認。

## 適用範囲と将来制度

2026年11月6日取得のe-Gov金商法改正履歴で、2026年法律64号の本体はUnEnforced。
APIの2027-07-22は「公布から一年以内に政令で定める日」に対応する施行予定欄で、確定した政令日として扱わない。
金融庁7月29日資料の8月12日は無登録業罰則等の部分施行であり、税制開始に流用しない。
税法の「関係規定施行年の翌年1月1日」という条件と改正の対象範囲のみを説明する。
2025/2026試算に将来の分離課税や付加税率を適用しない。将来の個別取引の申告可否は判定しない。
この条件付き将来制度の説明と2026年分の通常申告モデルについて重要な未確認事項は残っていない。
独立監査は年間内訳全フィールド・各増分を照合し、CSV/JSON/HTML表の一致は生成確認で検証する。
