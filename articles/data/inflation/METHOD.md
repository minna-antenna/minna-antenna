# 第9号：データ・計算・独立監査

調査2026-11-06 UTC。10年2016-09-30〜2026-09-30、5年2021-09-30〜2026-09-30。
主比較は月次121/61点、120/60か月の区間。CAGRは倍率^(12/区間月数)−1。

## データ

- GLD/SPY：Yahoo Finance日次closeとadjusted close。USD、米国市場取引日。基礎商品は運用会社で確認。
- BTC：第8号で公式Bitstamp APIから取得・検証したBTC/USD closeを再利用。原CSVをraw/BTC.gzへ保存し、上流とバイト照合。
- FX：Federal Reserve H.10、1USD当たりJPY、NY正午。ETF引け・BTC翌UTC00:00と同時ではない。
- 米国CPI：FRED CPIAUCNS。BLS CUUR0000SA0（CPI-U全国都市平均、総合、季節調整なし、1982–84=100）へ133か月分を別取得照合。
- 日本CPI：e-Stat「2025年基準長期時系列・全国中分類指数」の総合列。公式接続系列で1970年から最新まで。2026-09は102.2。
- 旧FRED日本系列JPNCPIALLMINMEIは2021-06で終了のため不採用。CPALTT01JPM661NはHTTP404で不採用。

raw/に圧縮元応答、sources.jsonに取得URL・日時・SHA256を保存。既存記事データは変更しない。
日次は全価格とFXが揃う共通日だけ。10年2,485点。欠測・休日を前値/補間で埋めない。
月次は各暦月最後の共通観測日。CPIはその暦月の値（公表日ではない）。事後分析であり公表前の売買ルールではない。
CPIは月次物価で、特定の月末時刻の物価ではない。同時刻で売買可能な運用成績ではない。

## 欠測と丸め

US CPIの2025-10はFREDが空欄、BLSが「-」。政府閉鎖による調査中断の公式説明を確認。
この1点はnullにし、USD実質・US CPI図を途切れさせる。日本CPIや近隣月で補わない。
5/10年端点・年末CPIは観測できる。年末比較や端点ベースの累積/CAGRには当該欠測を推定入力しない。
日本CPIは公表指数小数第1位から計算。公表前年比の丸め値とわずかに異なり得る。
計算途中は丸めず、表示率は小数第2位、円評価額のみ1円half-upで表示。

## 名目・実質・為替

USD倍率=P_t/P_0。JPY倍率=USD倍率×FX_t/FX_0（円/ドル）。
USD実質倍率=USD倍率÷(米国CPI_t/米国CPI_0)。JPY実質倍率=JPY倍率÷(日本CPI_t/日本CPI_0)。
実質リターン=(1+名目リターン)/(1+期間インフレ率)−1。名目年率から累積物価上昇率を引かない。
100万円モデル：各系列へ別々に一括投資。追加投資・引出し・ヘッジなし。
名目評価額=100万円×JPY倍率。実質評価額は開始月の日本の物価で測った購買力で、引き出せる現金額ではない。
個人の税金・売買/為替手数料・スプレッドなし。SPYの調整価格は税引前再投資の近似で、個人の実績を保証しない。
GLD/SPYの現在の経費率0.40%/0.0945%は商品説明。実績に内包された過去の費用を二重に差し引かない。
過去の費率が不変だったとも仮定しない。金地金・金先物・国内投信の実績とは区別。

## 年別と高インフレ年

年別：前年12月最終共通観測日→当年12月最終共通観測日。CPIは12月同士。
2022年例：2021-12-30→2022-12-30。公式ETFの別端点による暦年成績と必ず一致するとは限らない。
2026年は1〜9月の途中経過で年率換算しない。
高インフレ年は2017〜2025の完全な年だけ、米国12月CPI前年比>=4%、日本>=2%と編集上定義。
公表指数の比で判定。公的定義ではなく、年末値による事後分類で年初に分かる情報ではない。
相関・インフレサプライズ・因果寄与率・最適ポートフォリオを推計していない。

## 最大下落率と監査

日次共通観測値についてv_t/max(v_0...v_t)−1の最小値。USD・JPY名目を別に計算し、先にピーク・後に底。
BTC全暦日や全市場での最悪値ではない。第8号と期間/観測日が異なるため値も変わり得る。
本体のfloat走査とは別に、Decimal45桁でCAGR・実質・為替・年別・モデル評価額を再計算。
独立監査は原JSON/CSV/Fed表から日次全列を再照合し、月次は最終共通日とCPI対応を再検証する。
SPY40分配金を直前closeから再構成。GLD0分配金、両者分割なし。全日調整係数相対誤差1e-5未満。
下落は別の過去全値探索とDecimalで再判定。結果・日付・率・端点・図入力まで照合。
グラフ6種と高インフレ年比較表を作成。graph-audit.jsonで結果JSONとSVG/PNGのハッシュを検証。

## 再現（リポジトリのルート）

```sh
python -m scripts.prepare_inflation_data
python scripts/analyze_inflation.py --check
python scripts/audit_inflation.py
python -m unittest discover -s tests -v
```

原データから再構成してもCSVハッシュは不変。履歴データが後日訂正された場合は新しい保存先で取得・比較し、監査済みデータを黙って置換しない。
図再生成：`MPLCONFIGDIR=/tmp/topic-base-mpl python scripts/analyze_inflation.py --plots`（matplotlib）。
単位：USD名目指数、JPY名目/実質評価額（万円）、各実質指数、年別率（%）、名目DD（%）、CPI指数。
