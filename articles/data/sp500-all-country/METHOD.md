# 第6号：再現方法と条件

調査日：2026-11-06 UTC。主分析は2016-09-30〜2026-09-30、5年窓は2021-09-30〜同終点。
両ETFの共通公式月次資料は2026-09-30。最新営業日の値までの比較ではない。
指数の国比率・対象範囲は2026-10-30資料で、ETFの構成と基準日・対象が異なる。

## 対象と取得

- SPY（S&P500連動米国ETF）とACWI（MSCI ACWI連動米国ETF）の代理系列。
- eMAXIS Slim等の国内投信や、公式指数の日次系列そのものではない。
- Yahoo Finance Chart API：日次終値、調整後終値、配当、分割イベント。
- Federal Reserve H.10：日本円/米ドル。NDは欠測のままで前方補完しない。
- URL・実取得日時・応答SHA256：`sources.json`。元応答を `raw/*.gz` に保存。
- 構成・費用・公式照合値は発行会社の公式PDF。数値抜粋・資料URL・取得日時・応答ハッシュを `primary-facts.json` に保存。第三者PDF本文は再配布しない。

## 再現（リポジトリのルート、Python 3.12、標準ライブラリ）

```sh
python scripts/analyze_equity_comparison.py --check
python scripts/audit_equity_comparison.py
python -m unittest discover -s tests -v
python scripts/build_site.py
```

- 生成：`python scripts/analyze_equity_comparison.py`。表・JSON・仮定CSV・コード写しを同時生成。
- 図だけ任意依存matplotlib：`python scripts/analyze_equity_comparison.py --plots`。
- 新規取得は明示実行のみ：`python -m scripts.fetch_equity_comparison --output /tmp/equity-new-snapshot`。出力先が存在すれば停止し、既存保存値を上書きしない。通常CI・RSS・Pagesで取得しない。
- ダウンロード用`.py.txt`はリポジトリ内の同名スクリプトの完全な写し。実行には同リポジトリの既存計算モジュールも必要。

## 計算

両ETFとFXがそろう共通日だけ採用。円換算調整後値 = USD調整後終値 × 円/ドル。
CAGR = (期末/期首)^(365.2425/暦日数)−1。100万円期末額 = 1,000,000×期末/期首。
最大DD = min(V[t]/max(V[0:t])−1)。終値観測日だけで、日中最悪値や欠測日の下落を捉えない。
月次変動率 = 月末収益率の標本標準偏差×√12。5年60個、10年120個の月次収益率。
年別値は前年最終共通日→当年最終共通日。2016年と2026年は部分期間。

実データ積立：2016年10月末〜2026年9月末の120回、毎月末3万円を投入。
調整後単価で端数単位を購入できる仮想計算。初日の一括100万円とは別の計算。
税・売買費用・スプレッドゼロ、現金配当支払日や実際の再購入・端株制度を再現しない。
配当・分割調整は提供元の定義であり、公式の配当再投資実績そのものと同一ではない。
ETF内部費用は価格に反映されるため重複控除しない。
FXはFRBの別時刻の観測値で、ETF終値と同時約定できる価格ではない。

仮定積立：月3万円、実効年率0/3/5/7%、10/20/30年の12条件。初期0・月末。
月率m = (1+r)^(1/12)−1。年率/12ではない。最終額 = P×((1+m)^n−1)/m、0%はP×n。
利回りは円建て名目、継続費用控除後の仮定。購入時費用等ゼロ。
適格NISA利用・他の買付なし、日本の投資家段階課税はゼロという仮定。
外国税の免除を意味せず、現金分配の外部再購入による枠消費はモデル化しない。
相場変動・インフレなし。実際にはマイナスや元本割れがある。
Decimal50桁で計算、最終円額だけROUND_HALF_UP。元本との差額は表示額−元本。
両指数の将来予測ではなく、同条件なら同額となる。

## 独立検算と一次資料照合

`audit_equity_comparison.py`は独立実装で生応答→CSVを照合し、毎日の配当調整係数を復元。
分割を検知した場合は未対応として停止し、黙って処理しない。今回の2系列は分割0。
CAGR・DD・月次変動率・年別値はDecimal60桁で別計算。
過去積立は本体の保有単位合計法と別の残高漸化式、仮定積立も月次漸化式で再検算。

2026-09-30の公式年率（米ドル建て）：SPY Market Valueは5年13.66%、10年15.18%。
ACWI Market Priceは5年11.64%、10年12.45%。独自の調整後終値とは同一の評価方法ではない。
SPY公式は売買気配の中値を使用。観測された差は記事の照合表に開示。
4件すべてで絶対差0.10パーセントポイント未満を確認するが、これは一致の証明でも精度保証でもなく逸脱検出の上限。
差の全額を特定要因に帰属させない。公式値と独自の近似をそれぞれの名前で表示する。

ACWIの設定は2008年で、同ETFを使う20年の共通実績は2026年時点では存在しない。
短い実績を継ぎ足したり指数のバックテストを実運用と呼んだりしない。
