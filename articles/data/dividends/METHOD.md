# 第10号：比較条件と再現方法

調査・取得：2026-11-07 UTC（日本時間も同日）。原本取得日時は sources.json。

## 再現

リポジトリのルートで Python 3.11 以上を使用：

```
python scripts/analyze_dividends.py --check
python scripts/audit_dividends.py
python -m unittest discover -s tests -v
python scripts/build_site.py
# 再実行時に index.html / sitemap.xml が変わらないことを確認
```

表・JSONを再生成する場合は --check を外す。グラフは Matplotlib 3.10.8 で
`MPLCONFIGDIR=/tmp/article10-mpl python scripts/analyze_dividends.py --plots`。
ネットワークなしで凍結原本から全数値を再計算できる。raw/*.json.gz は Yahoo Finance
レスポンスの原本、sources.json の SHA-256 で保全。圧縮 gzip の mtime は0。
Pythonファイルの公開コピーは .py.txt。GitHubでは scripts/ に実行用を保存。

## 実績

- VYM / SPY、米ドル、米国市場の営業日ラベルの日次終値。
- 2016-09-30〜2026-09-30：2,513日、121月末観測、120月間。
- 2021-09-30〜2026-09-30：1,255日、61月末観測、60月間。
- API取得範囲2015-09-01〜2026-09-30（終点指定は翌日を排他的に指定）。
- 補間・欠損の前日値埋めは行わず、2資産の日付の一致を要求する。
- 終値比と調整後終値比を区別。後者は分配金調整の市場価格系列、個人課税前の
  再投資の近似。NAV、指数、国内投信、個人手取と同一ではない。
- 遡及係数は各分配落ち日の `1 - 分配額 / 前取引日終値` を積み上げる。
  Yahooの調整後/非調整価格比との相対誤差を検証（許容1e-5：浮動小数点の
  価格保存精度を考慮。実測は両資産6e-7未満）。未審査の分割があれば停止。
- 配当利回りは2025-09-30を含まず2026-09-30を含む分配額の合計÷最終終値。
  支払日ベースの家計入金でも、SEC利回りでも、予想でもない。
- CAGR=(調整後終値比)^(1/年数)-1。分配を別途加算しない。
- 最大下落率：各営業日について調整後価格/その日までの最高調整後価格−1、の最小。
  開始日以前の高値・日中安値・円換算・受取型のMDDではない。
- 変動率：共通月末リターンの標本標準偏差（ddof=1）×sqrt(12)。
- 年別：前年最終営業日→当年最終営業日、2026年は9月までを別表示。
- 現在の費用率を過去に一律控除せず、実績価格に反映済みとする。
- 発行会社公式の2026-09-30市場価格CAGR：VYM 5年11.64/10年11.28%、
  SPY 5年13.65/10年15.18%。VYMは当分析の丸めと一致。SPYは約0.05ポイント差。
  Yahooの分配落ち遡及調整と公式市場価格リターンを同じ算定系列とせず、差を記事に明記。
  正確な発行会社算定価格・再投資日への一致は未検証。小差を隠したり原本を調整しない。

## 仮定モデル（実績と別）

1. 月末3万円、開始ゼロ、実効年率0/3/5/7%、10/20/30年。
   月利=(1+年率)^(1/12)-1。閉形式をfloatで計算し、Decimal45桁の毎月積上げで独立照合。
   税・売買費・FX変化ゼロ。利回りは運用中の継続費用控除後を仮定。
2. 100/300/500/1000万円 × 仮定配当利回り2/3/4/5%。年額÷12は月平均にすぎない。
3. 初期100万円、年末総収益6%、分配は年初残高の3%、価格成長3%、20年。
   再投資は資産×1.06、現金受取型は運用資産×1.03＋現金積上げ（現金利息ゼロ）。
   再投資額と現金を同時加算しない。受取累計と運用残高の合計も示す。
4. 売却型は全額残存する総収益6%の資産から年初残高の3%を年末売却。
   分配型と残高・累計現金が一致することを検証。同じ率でも固定額引出しではない。
5. 税・手数料・売買単位・端数株制約は除外。個人の税引後試算ではない。
   税制説明は2026年現行制度。国税庁各ページの法令基準日は2026-04-01。
   外国税の一律の率や還付保証を置かず、NISA国内非課税と外国課税を分ける。

表示丸め：リターンは小数第2位%、円は最終表示で整数（最近接偶数）。
月平均分配は小数第2位円、内部精度は保持。予測・保証・個別助言ではない。
